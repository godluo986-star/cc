# 美术设计方案 —— 「暗黑都市·奇幻动画风」新地图(内部代号:黄昏街区 / Dusk Ward)

> 本文档是新版户外地图与三大场馆(电影院、网吧、棋牌房)的美术与技术总纲。
> 先方案后代码:所有实现工单以本文档为验收依据。
> 参考的只是视觉语言(现代都市 × 暗黑奇幻 × 日式动画 × 超自然),不复制任何
> 现有作品的角色、标志、具体建筑或镜头。

---

## 1. 总体美术方向

**一句话**:黄昏到夜晚之间的现代日本街区,湿冷、安静、带着一点说不出的不对劲;
玩家(圆滚滚的团子)是画面里唯一柔软高饱和的存在,与城市形成强烈反差。

- 时代与地点:当代日本市中心繁华街的背巷一侧 —— 大型十字路口 + 商业楼 +
  高架人行天桥 + 地铁站入口 + 窄巷。像动画里的"事件发生前一小时"。
- 情绪:冷、压抑、神秘,但**不是全黑**;远处永远有城市灯光,近处永远有一两盏
  暖灯可以靠近。
- 统一性:整图一套色板、一套 toon 材质、一套描边、一套后期。任何新物体先问
  "在这套色板里吗?在这套明暗层级里吗?"
- 团子角色保持现有粉彩配色不变(高饱和强调色配额的一部分),运动时的
  squash-and-stretch 是画面里唯一"欢快"的节奏,刻意保留这种反差萌。

## 3. 灯光方案

不做"整景均匀照亮"。电影化三层布光:

1. **主方向光(月光/残照)**:方向从西偏北 25° 俯角 35°,颜色 `#8d99c9`,
   强度 0.55;投影只覆盖玩家周围 60m(shadow camera 跟随),
   形成清晰的长影。阴影颜色靠 hemisphere 冷底托住,不发黑死。
2. **弱冷环境光**:hemisphere sky `#39415f` / ground `#23262f`,强度 0.28。
   保证大暗部里仍读得出形体。
3. **局部暖光(有限数量,做构图焦点)**:
   - 路灯:间隔 22-28m,一盏一个 pointLight(`#e8a84c`,半径 14m,衰减 2),
     同屏预算 ≤ 10 盏真实光源,其余用贴图自发光假光。
   - 店门口/亮窗:自发光材质 + 每家最多 1 个小半径光。
   - 玩家轻微轮廓光:一个跟随玩家的 0.35 强度冷青 rim(方向与主光相对),
     让团子从暗部里"浮"出来。
4. **阴影哲学**:暗部占画面 35-50%;天桥下、巷口、卷帘门前刻意留大块阴影
   作为构图负空间;重要通道用光带引导(路灯列 → 路口 → 目标店招)。
5. **超自然光污染**:异常点(见 §6)半径 3-6m 内,环境光被"污染"成蓝紫/青绿
   (lerp 0.2),灯光低频闪烁(1/17s 概率抖 8%),离开即恢复。

日夜循环保留但重新标定:本图默认停在「黄昏→夜」区间循环(20 分钟),
白天段压缩为阴天灰蓝(保持氛围统一,不出现明媚正午)。

## 4. 场景结构(新户外图:黄昏街区)

**尺度**:可活动核心区 **520m × 520m**(bounds ±260),配合奔跑速度上调
(街道 7m/s,室内不变);视觉城市(不可进入的背景楼群、更远的天际线)延伸到
约 1.2km 直径,用三层剪影 + 分层雾表现。
(说明:字面 1km 步行去任何店都要 2 分钟以上,会空;520m 核心 + 视觉延伸
在镜头里就是"一整个街区",这是尺度与好玩之间的取舍,已在实现中写死可调常量。)

### 4.1 平面结构(中景 = 可玩区)

```
                         N
        ┌─────────────────────────────────┐
        │  高架天桥(可上,俯瞰路口)      │
        │  ══════════╗                    │
        │   旧公寓巷  ║   商业楼群(视觉) │
        │   (异常点A) ║                    │
        │            ▼                    │
        │   ┌──── 大十字路口 ────┐        │
        │   │  斑马线×4 中央菱形  │        │
        │  西街 ─────╬───── 东街          │
        │   │ 网吧NEXUS │ 电影院AURORA    │
        │   │ 便利店    │ 街机厅          │
        │   └──── 南站前广场 ────┘        │
        │    地铁站入口(下沉台阶,封闭)   │
        │    雀庄东风阁 · 咖啡馆 · 团子塔  │
        │    窄巷网(异常点B,垃圾袋/海报) │
        └─────────────────────────────────┘
                         S
```

- **大十字路口(中心地标)**:四向斑马线 + 对角线,路口四角是本图最高
  楼(视觉 40-70m,不可进入),包围感;红绿灯慢循环,红灯时远处传出
  提示音(空间音频)。
- **主街两条**(东西 + 南北):两侧骑楼式店面,一层全是可读细节
  (卷帘门、招牌、菜单立牌、空调外机、配电箱),二层以上渐简。
- **站前广场(南)**:出生点。地铁入口下沉 6 级台阶后被拉闸封住
  (灯还亮着,异常感来源之一);公告栏(留言板)、公用长椅、公共电话亭。
- **高架人行天桥(北)**:唯一的垂直可玩层,上桥俯瞰整个路口
  (heightZones 坡道),桥上视角是本图"名片镜头"。
- **窄巷网(东南/西南)**:1.8-2.4m 宽,拐两次弯;垃圾袋、竖招牌、
  滴水空调、自行车;异常点 B 藏在巷底。
- **场馆门(全部在主街一层)**:电影院 AURORA、网吧 NEXUS、雀庄东风阁、
  便利店(原商店)、街机厅、咖啡馆、团子塔(个人房间入口,保留)。

### 4.2 三层景深

- **前景(相机常穿过)**:栏杆、电线束、灯杆、门框、悬挂电缆、树枝。
  规则:玩家 3m 内至少常有一件前景遮挡物可入画。
- **中景**:上面 4.1 的全部可玩内容,细节预算的 70% 花在这里。
- **背景**:三层剪影楼群(`#2b3040/#343a4d/#3e4459`)+ 零星亮窗
  (自发光点阵贴图)+ 天际线水塔/吊车剪影 + 分层雾;完全不可达,
  多边形预算 < 5%。

### 4.3 生活感道具清单(不均匀布置,成组讲故事)

自动售货机(红/蓝,可互动买饮料)、路牌/门牌、空调外机(滴水渍)、
成堆垃圾袋 + 乌鸦(会飞走)、旧海报墙(边角翘起,微摆动)、自行车
(斜靠,个别倒地)、储物柜(站前)、电线杆 + 横跨街道的电缆(缓慢晃动)、
施工围栏(一处,黄黑条)、雨水痕迹(墙面 decal)、井盖、消防栓、
灭火器箱、二楼晾衣杆。

**布置原则**:每 30m 街段 1 个"道具事件组"(如:倒下的自行车 + 散落传单 +
一只乌鸦),其余留白;禁止等距阵列。

### 4.4 室内场馆

- **电影院 AURORA**(已有,微调):16×6.4m 满墙巨幕保留;按本图色板重刷
  (深红座椅 → `#6e3b47`,墙 `#2b2129` 保留);增加:银幕"沉浸观影"全屏
  按钮(见 §7)、共享画面投上巨幕。
- **网吧 NEXUS(新室内)**:两排 8 座电竞位,每座一台 27" 曲面感显示器

  邻座路过能看;墙上一块 6m 联赛大屏,可把任何在场玩家的共享画面投上去;
  蓝青灯带 + 桌下 RGB(克制,低亮度),饮料架、耳机挂钩、泡面堆。
- **雀庄「东风阁」(新室内)**:和风暖木 + 障子纸窗;2 张全自动麻将桌
  (日麻,含点数显示屏)+ 1 张象棋桌;墙上役种一览挂轴、点棒柜台、
  茶水台。日麻 UI 要求见 §8。

## 5. 渲染与材质规范

- **Toon 分层**:所有材质 MeshToonMaterial + 共享 4 阶 gradientMap
  (夜景版:0.32/0.55/0.78/1.0,避免死黑);重要物体(角色/售货机/招牌)
  3-4 阶,背景物 2 阶。
- **描边系统**(`city/outline.ts`):反转外壳法统一实现;粗细 = clamp(
  0.008 × 距离衰减, 0.002, 0.014) —— 远处自动变细;背景剪影楼不描边。
- **手绘质感**:512px 程序化 canvas 贴图(已有基建):混凝土脏渍、
  墙面雨痕、海报纸纹、沥青斑块;同一贴图多物体间旋转/偏移复用,禁止
  肉眼可见的重复平铺。
- **禁止**:金属高反射、clearcoat、镜面地面(雨后路面用"假反射":
  低透明度倒置贴花 + 灯位高光点)、默认 Three.js 天空、纯黑。
- **重复物体变化**:实例化物体(护栏、空调、垃圾袋)必须带
  per-instance 色相 ±3%、明度 ±6%、旋转 ±4°、尺寸 ±8% 抖动(种子确定)。
- **圆角**:近景可交互物体几何倒角或法线柔边;远景不做。

## 6. 超自然氛围(低频、克制)

| 异常 | 位置 | 表现 | 频率 |
| --- | --- | --- | --- |
| 影子迟到 | 天桥下 | 玩家影子偶尔慢半拍(shader 延迟采样旧位置) | 进入区域后 ~90s 一次,持续 2s |
| 墨迹扩散 | 巷底 B 点 | 墙面墨渍 decal 缓慢生长又缩回 | 常驻,周期 45s |
| 逆重力纸张 | 站前广场 | 3-4 张传单向上飘,到 2m 处消散 | ~60s 一次 |
| 灯闪 | 异常点半径 6m | 路灯 8% 亮度抖动 + 音频嗡声变调 | 常驻低频 |
| 天桥人影 | 高架远端 | 一个看不清的剪影,靠近 20m 内即不在 | 每晚 1-2 次 |
| 黑色碎片 | 异常点 A | 6-10 片缓慢上浮的黑片(不发光) | 常驻,速度不一致 |

全部只做视觉/音频,无 gameplay 影响;实现集中在 `city/anomalies.tsx`。

## 7. 后期与镜头

- **后期栈**(高质量档):SMAA → Bloom(threshold 0.82, intensity 0.28,
  只让招牌/灯芯起光晕)→ 色调映射 ACES → 颜色分级(LUT 式曲线:阴影偏蓝
  `+0.03`,高光偏暖 `+0.02`,整体去饱和 -8% 再对强调色回饱和)→ SSAO
  (半径 0.4,强度 0.35,仅高档)→ 轻暗角 0.4 → 胶片颗粒 0.035 →
  色差 0.0008(极轻)。禁止大范围 bloom 糊屏。
- **镜头**:第三人称跟随高度从团子胸口起算(lookAt ~0.6m),FOV 由 50°
  收到 **42°**(≈45mm 等效),拉远上限 12m;入口/路口用建筑光带引导视线;
  重要构图(出生点第一帧、天桥俯瞰)已在布置中做不对称配重。

## 8. 日麻(立直麻将)—— 雀魂级观感要求

- **规则引擎(shared)**:四人东风战;立直/一发/门清自摸/断幺/平和/役牌/
  对对/七对/混一/清一/国士 + 宝牌·里宝牌;吃碰杠(明暗加),振听,流局
  听牌料;点数:符数简化为常见档(20/25/30/40),满贯以上按跳满/倍满/
  役满;缺人 AI 补位(牌效率启发式)。规则简化点在 README 诚实列出。
- **2D 操作面板(雀魂式)**:底部手牌扇形排列、理牌动画、切牌浮起提示、
  可点"立直"后自动摸切;吃碰杠荣和按钮带 8s 倒计时圈;中央信息盘
  (风位、供托、本场、点数、宝牌指示牌);和牌结算页:役种逐条点亮 +
  翻符翻番动画。牌面用 canvas 精绘(万筒索字四色规范,红宝牌 5)。
- **3D 桌面(旁观真实视角)**:全自动麻将桌模型、牌河按 6 列摆放、
  副露在右手边、立直棒横置、点数屏发光;旁观者看得到全桌但看不到
  任何人的手牌(服务器脱敏,复用福州麻将的 viewFor 机制)。

## 9. 媒体与共享屏幕整合(本期一并修)

1. **同步验证**:自动化测试证明两客户端 `mediaTargetPosition` 偏差
   < 0.5s(服务器时钟外推),YouTube/视频档位一致。
2. **全屏观影**:媒体激活时屏幕面板出现「⛶ 全屏观看」:用**固定定位 DOM
   覆盖层**(非 CSS3D)按视口原生分辨率重建同源播放器,进度仍走同一套
   同步逻辑;Esc/按钮退出。解决 CSS3D 全屏分辨率不占满的问题。
3. **共享画面上大屏**:影院巨幕/网吧墙屏/网吧座位屏支持"投屏":
   在屏幕面板选择在场共享者 → 服务器把 media 状态设为
   `{kind:'share', ownerId}` → 各客户端把该玩家的 WebRTC 视频流贴到
   对应大屏(纹理化 video);共享者离开/停止即自动清屏。

## 10. 性能预算与分级

| 档位 | 判定 | DPR 上限 | 阴影 | 后期 | 真实光源 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| Ultra | 桌面独显 | 2.0 | 2048 PCF | 全开 | 10 | SSAO 开 |
| High(默认桌面) | 桌面 | 1.75 | 1024 | 全开(无 SSAO) | 8 | |
| Medium | 弱桌面/大屏移动 | 1.5 | 512 仅主光 | SMAA+暗角 | 5 | 颗粒/色差关 |
| Low(移动默认) | `navigator.userAgentData.mobile` 或 deviceMemory ≤ 4 | 1.25 | 关 | 关 | 3 | 前景装饰减半、背景两层 |

- 硬预算:桌面 draw call ≤ 350 / 三角形 ≤ 90 万;移动 ≤ 180 / 45 万。
  街道道具全走 InstancedMesh;背景剪影合并为 ≤ 6 个网格。
- **LOD**:建筑三档(完整 → 无道具细节 → 剪影),切换距离 45/110m,
  雾内直接剔除;室内空间保持按需渲染(已有)。
- **加载**:程序化生成分帧执行(每帧 ≤ 8ms),加载界面显示阶段进度
  (布局→贴图→建筑→道具→灯光);首屏优先生成出生点 80m 半径,其余
  空闲帧补齐。
- **资产管线**:GLTFLoader + DRACOLoader + KTX2Loader 注册在
  `city/loaders.ts`(带 basis transcoder 本地路径),当前资产仍全程序化
  (零外部文件),管线为后续导入高精模型预留,README 注明。
